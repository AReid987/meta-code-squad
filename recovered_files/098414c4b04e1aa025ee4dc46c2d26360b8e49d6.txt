## What It Is

Meta Code Squad is a **multi-agent autonomous development system** — the engine that powers all Aigency products. It orchestrates specialized AI coding agents to plan, build, test, and ship software with minimal human intervention.

**Core capabilities:**

- **Self-orchestrating** — Agents coordinate via Ruflo's queen/worker topology
- **Quota-proof** — SimpleLLMRouter v2 distributes across 8+ free-tier providers (~1B tokens/month)
- **Memory-persistent** — Letta + Ruflo AgentDB preserve context across sessions
- **Quality-gated** — forge-quality enforces lint, typecheck, security, and coverage at commit time
- **24/7 capable** — Sugar AI task queue + Loki Mode enable overnight autonomous builds

## Agent Ecosystem

| Agent | Role | Best For |
|-------|------|----------|
| **Ruflo** | Orchestrator | Planning, coordination, swarm management |
| **Gemini CLI** | Primary throughput | GSD, tests, config, boilerplate, docs |
| **Claude Code** | Complex logic | State machines, security, architecture |
| **Kimi Code CLI** | Review | 128K context full-codebase sweeps |
| **iFlow CLI** | Utilities | `/scaffold`, `/qa`, `/refactor`, `/mermaid` |
| **Letta Code** | Memory | Persistent codebase context, `/init deep` |

**Routing flow:**
```
New feature → Ruflo plans → Gemini designs → Kimi implements → iFlow reviews
Bug fix     → Ruflo triages → Kimi patches → iFlow validates
Architecture → Gemini leads → Ruflo coordinates → all agents input
```

## Quick Start

### Prerequisites

- Node.js 20+
- Python 3.12+
- `just` (task runner)

```bash
# Install just (one time)
brew install just          # macOS
# or: cargo install just   # Linux/Windows
```

### Setup

```bash
git clone git@github.com:AReid987/meta-code-squad.git
cd meta-code-squad
just setup   # One-time: installs all tools, wires services
just dev     # Start everything for a work session
```

### First Session

```bash
# In Claude Code:
/init deep              # Letta indexes the codebase (~10 min, once)

# Generate first plan:
/gsd:new-project        # Creates PROJECT.md, REQUIREMENTS.md, ROADMAP.md
/gsd:plan-phase 1       # Generates PLAN-1.md

# Execute autonomously:
just run PLAN-1.md      # Loki consumes plan, RARV cycle begins
```

## Packages

### `packages/llm-router` — SimpleLLMRouter v2

Intelligent LLM routing gateway with:
- **14-dimension complexity classifier** — routes to optimal model
- **3-layer semantic cache** — 30-60% token savings
- **Circuit breaker + quota tracking** — never hit limits
- **Textual TUI** — 9 screens for real-time monitoring

### `packages/forge-quality` — Code Quality Enforcer

Git hook enforcement system:
- **Pre-commit**: format, lint, typecheck, secret scan
- **Commit-msg**: conventional commits validation
- **Pre-push**: full test suite, security audit
- **PR generator**: auto-generate descriptions from commits

### `packages/lp-gen` — Landing Page Generator

Agent-driven landing page builder for Aigency sub-domains.
