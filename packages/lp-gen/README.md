# lp-gen

Landing page generator for Aigency subdomains.

## Overview

AI-assisted landing page generation pipeline. Takes a product brief and outputs
a production-ready landing page (HTML/CSS/JS or Next.js component).
Part of the meta-code-squad monorepo.

## Status

Scaffolded. Design system and copy specs in docs/ux-specs-aigency-dev-platform.md.

## Quick Start

```bash
just lp-gen-dev
```

## Pipeline

1. Discovery Specialist — extracts requirements
2. Market Research Specialist — competitive analysis
3. Strategy Director — page strategy
4. Copy Optimizer — section copy
5. Design System Architect — visual system
6. Landing Page Architect — production code

## Agent Ownership

Owned by the landing-page-* agent squad in Nebula.
Orchestrated via meta-code-squad justfile commands.
